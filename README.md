While I am just getting started on my computer science journey from here, take a look at what led me here.

Enhancement 1 is a barebone inventory management system originally designed in class for Android using Android studio. It follows security guidelines as listed by OWASP, while still serving extremely simple functionality and user interface design. My enhancement was to bring this app to life in a different environment, iOS. iOS is particularly difficult to access if its your first time developing on it, however once you get your system up and running, the intuitive logic of swift makes life much easier for application developers and mobile phone users. Throughout this enhancement you will see my struggles, and successes, as well as how I managed to navigate the now more cohesive multi-platform app development.

Enhancement 2 is a project on OpenGL I was working on during through the birth of my first born son, so particularly hazey eyed I managed to pull off some high level computer graphics work. Using the latest OpenGL tools and my favorite math I developed a simple evironment with some complex shapes dictated by my math equations for the creation of my sons Bassinet in my living room, and honestly it was the only thing I could think of when the professor prompted us to come up with an environment to create. The enhacement for me had to do with my code not running efficiently enough. I added sine logical changes to how the objects were rendered, and some tweaks to the environment itself, this also includes the implementation of a FPS counter and a time between frames counter, this was to verify that my changes actually made an impact.

Enhancement 3 is a jupyter notebook / Python project using Mysql and mongoDB for data visualization. This originally projected while developed on jupyter notebook using a mongoDB backend, I had modifed in my enhancement to make it portable. In this development I found numerous ways to better use data from a CSV file, this included learning how python and mongoDB trade off date for it to be represented in whichever way I tell it to. With some simple user controls I also made the data set more productive as you can now understand different parts of the data and how it varies through a timeline. 

SNHU has given me the ability to showcase not just my development skills, creative problem solving, but also my ability to adapt and grow as more information came out helping me pursue a more complete version of myself in software engineering and computer science as a whole.
